# Security policy

## Reporting a vulnerability

Please do not disclose a security issue publicly before it can be reviewed. Report suspected vulnerabilities to **ketan6196@gmail.com** with:

- the affected URL or file;
- steps to reproduce;
- expected and actual behavior;
- potential impact; and
- a suggested fix, if available.

A response will be attempted within seven days. This personal static site has no authenticated backend and does not collect form submissions or payment data.

## Supported version

Only the currently deployed version at <https://ketandutt.github.io/> is supported.

## Contributor guidance

Never commit credentials, tokens, private keys, private personal information, or proprietary project assets. Browser code is public and must not contain secrets. External dependencies and links should use HTTPS.
